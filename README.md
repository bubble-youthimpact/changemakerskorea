# Changemakers Korea · UN SDGs Idea Competition

Static website for GitHub Pages.

## Publish
1. Upload everything in this folder to the root of a GitHub repository (keep the folders as they are).
2. Repository **Settings → Pages → Build and deployment**: Source **Deploy from a branch**, Branch **main** / **(root)** → Save.
3. Custom domain (optional): enter `changemakerskorea.org` under **Settings → Pages → Custom domain**, then point the domain's DNS to GitHub Pages.

## Apply form
- Drafts and applications: Firebase Firestore (config is in `index.html`, search `FIREBASE_CONFIG`).
- Application emails with the pitch deck attached: FormSubmit → bubble.youthimpact@gmail.com.
- One-time setup steps and the Firestore rules are in `setup/`.
